FreeCAD PDM System

Implementation Document

1. Overview

Purpose

A minimum Product Data Management (PDM) system for managing FreeCAD CAD files in a small team environment with multiple projects.

Core Principles

Principle Description
Simplicity Manual processes, no complex software
Exclusive editing One person edits a file at a time
Traceability Track revisions and changes
Flexibility JSON-based, extensible for future automation

System Components

Component Implementation
Storage Local folder or network drive
Version control Manual revision tracking
Locking mechanism checkout.json
Metadata JSON files + FreeCAD properties
Relationships relationships.json

2. Part Numbering

Format

Type Prefix Digits Example
Part P 6 P000001
Assembly A 6 A000001

Rules

  • Numbers are sequential
  • Numbers are never reused
  • Drawings reside inside part/assembly files
  • Capacity: 999,999 parts + 999,999 assemblies

3. File Naming Convention

Format

{Number}.FCStd

Examples

P000001.FCStd
P000002.FCStd
A000001.FCStd

Rules

  • No description in filename
  • No revision in filename
  • Description and revision stored inside file and index.json

Archive Naming

{Number}_Rev{Revision}.FCStd

Examples

P000001_RevA.FCStd
P000001_RevB.FCStd
A000001_RevA.FCStd

5. FreeCAD Custom Properties

Required Properties

Property Type Description Example
PartNumber String Part number (or AssemblyNumber for assemblies) P000001
Description String Part/assembly description Motor Mount Bracket
Revision String Current revision letter A
Status String Current status working
Author String Original creator John
LastModifiedUser String Last person to edit Mary
LastModified String Date of last modification 2024-01-15
ChangeNote String Description of last change Added mounting holes
Material String Material specification Aluminum 6061
Density Float Material density (g/cm³) 2.7
Volume Float Part volume (cm³) 125.5
Weight Float Part weight (g) 338.85

Notes

  • Use PartNumber for parts
  • Use AssemblyNumber for assemblies
  • Volume and Weight can be calculated by FreeCAD

6. Status Flow

Statuses

Status Description
working Under development, can be modified freely
released Approved for use, locked
obsolete No longer used, kept for reference

Flow

working → released → obsolete

Rules

From To Action
working released Release approval
released working Not allowed directly (create new revision)
released obsolete Deprecate part
obsolete - Terminal state

7. Revision Concept

Key Rule

Revision changes ONLY when a RELEASED part/assembly needs modification.

Revision Scheme

A → B → C → D → ... → Z → AA → AB → ...

Lifecycle

1. Create new part
   → Revision: A, Status: working
   
2. Work on it (multiple saves)
   → Still Revision: A, Status: working
   
3. Release it
   → Revision: A, Status: released
   
4. Need to modify?
   → Archive current file
   → Create new Revision: B, Status: working
   
5. Release new revision
   → Revision: B, Status: released

Rules

Rule Description
New parts start at Rev A Always
Working parts stay at current revision Multiple edits, same revision
Revision increments on released modification Archive old, increment revision
Archived files are read-only Never modify archived files

8. JSON Files

8.1 index.json

Master register of all parts and assemblies.

{
  "meta": {
    "version": "1.0",
    "last_updated": "2024-01-15",
    "next_part": 3,
    "next_assembly": 2
  },
  "parts": {
    "P000001": {
      "description": "Bracket",
      "project": "PRJ-001",
      "revision": "B",
      "status": "released",
      "revision_history": [
        {
          "revision": "A",
          "date": "2024-01-10",
          "user": "John",
          "note": "Initial release",
          "archived": "PROJECTS/PRJ-001_ProjectName/parts/_archive/P000001_RevA.FCStd"
        },
        {
          "revision": "B",
          "date": "2024-01-15",
          "user": "Mary",
          "note": "Added mounting holes",
          "archived": null
        }
      ]
    },
    "P000002": {
      "description": "Housing",
      "project": "PRJ-001",
      "revision": "A",
      "status": "working",
      "revision_history": []
    }
  },
  "assemblies": {
    "A000001": {
      "description": "Motor Mount",
      "project": "PRJ-001",
      "revision": "A",
      "status": "working",
      "revision_history": []
    }
  }
}

8.2 checkout.json

Tracks which files are currently being edited.

{
  "P000001": {
    "user": "John",
    "date": "2024-01-15"
  }
}

Empty when no files are checked out:

{}

8.3 relationships.json

Tracks assembly contents (BOM).

{
  "meta": {
    "version": "1.0",
    "last_updated": "2024-01-15"
  },
  "assemblies": {
    "A000001": {
      "contains": [
        {"item": "P000001", "qty": 2},
        {"item": "P000002", "qty": 1}
      ]
    },
    "A000002": {
      "contains": [
        {"item": "P000003", "qty": 1},
        {"item": "A000001", "qty": 2}
      ]
    }
  }
}

System configuration settings.

{

  },
  "numbering": {

  },
  "status_values": [
    "working",
    "released",
    "obsolete"
  ],
  "revision_scheme": "alpha",
  "users": [
    "John",
    "Mary",
    "Bob"
  ]
}

9. Workflows

9.1 Create New Part

1. Open index.json
   → Get next_part number (e.g., 3)
   → New part number: P000003

2. Create new file from template
   → Save as: PROJECTS/PRJ-001_ProjectName/parts/P000003.FCStd

3. Set FreeCAD properties:
   - PartNumber: P000003
   - Description: [description]
   - Revision: A
   - Status: working
   - Author: [your name]
   - LastModifiedUser: [your name]
   - LastModified: [today's date]
   - ChangeNote: Initial creation
   - Material: [if known]
   - Density: [if known]
   - Volume: [calculated]
   - Weight: [calculated]

4. Save file

5. Update index.json:
   - Add new entry under "parts"
   - Increment next_part to 4
   - Update last_updated

6. Done

9.2 Create New Assembly

1. Open index.json
   → Get next_assembly number (e.g., 2)
   → New assembly number: A000002

2. Create new file from template
   → Save as: PROJECTS/PRJ-001_ProjectName/assemblies/A000002.FCStd

3. Set FreeCAD properties:
   - AssemblyNumber: A000002
   - Description: [description]
   - Revision: A
   - Status: working
   - Author: [your name]
   - LastModifiedUser: [your name]
   - LastModified: [today's date]
   - ChangeNote: Initial creation

4. Save file

5. Update index.json:
   - Add new entry under "assemblies"
   - Increment next_assembly to 3
   - Update last_updated

6. Update relationships.json:
   - Add assembly entry with empty contains list

7. Done

9.3 Edit Working Part/Assembly

1. Check checkout.json
   → Is file listed? → STOP, file is in use
   → File not listed? → Continue

2. Add entry to checkout.json:
   {
     "P000001": {
       "user": "[your name]",
       "date": "[today's date]"
     }
   }

3. Open and edit file in FreeCAD

4. Update properties:
   - LastModifiedUser: [your name]
   - LastModified: [today's date]
   - ChangeNote: [what you changed]

5. Save file

6. Update index.json:
   - Update last_updated

7. Remove entry from checkout.json

8. Done

9.4 Release Part/Assembly

1. Verify part/assembly is complete and approved

2. Open file in FreeCAD

3. Update properties:
   - Status: working → released
   - LastModifiedUser: [your name]
   - LastModified: [today's date]
   - ChangeNote: Released

4. Save file

5. Update index.json:
   - status: "released"
   - Add entry to revision_history:
     {
       "revision": "A",
       "date": "[today's date]",
       "user": "[your name]",
       "note": "Initial release",
       "archived": null
     }
   - Update last_updated

6. Done

9.5 Modify Released Part/Assembly (New Revision)

1. Check checkout.json
   → Ensure file is not in use

2. Add entry to checkout.json

3. Copy current file to archive:
   P000001.FCStd → _archive/P000001_RevA.FCStd

4. Open original file in FreeCAD

5. Update properties:
   - Revision: A → B
   - Status: released → working
   - LastModifiedUser: [your name]
   - LastModified: [today's date]
   - ChangeNote: [reason for new revision]

6. Save file

7. Update index.json:
   - revision: "B"
   - status: "working"
   - Update previous revision_history entry:
     - archived: "PROJECTS/PRJ-001_ProjectName/parts/_archive/P000001_RevA.FCStd"
   - Add new revision_history entry:
     {
       "revision": "B",
       "date": "[today's date]",
       "user": "[your name]",
       "note": "[reason for revision]",
       "archived": null
     }
   - Update last_updated

8. Make required changes

9. When complete, follow Release workflow (9.4)

10. Remove entry from checkout.json

11. Done

9.6 Mark Part/Assembly as Obsolete

1. Open file in FreeCAD

2. Update properties:
   - Status: released → obsolete
   - LastModifiedUser: [your name]
   - LastModified: [today's date]
   - ChangeNote: Marked obsolete - [reason]

3. Save file

4. Update index.json:
   - status: "obsolete"
   - Update last_updated

5. Done

9.7 Update Assembly Contents (BOM)

1. After modifying assembly contents in FreeCAD

2. Update relationships.json:
   "A000001": {
     "contains": [
       {"item": "P000001", "qty": 2},
       {"item": "P000002", "qty": 1},
       {"item": "P000005", "qty": 4}
     ]
   }

3. Update meta.last_updated

4. Done

10. Search & Retrieval

Methods

Method Use For
File browser Find by part number
Text search in index.json Find by description, project, status
Search relationships.json Find where a part is used

Finding a Part

  1. Know the number? → Browse to project folder
  2. Know the description? → Search index.json
  3. Know the project? → Browse project folder

Finding Where-Used

  1. Open relationships.json
  2. Search for part number
  3. Note which assemblies contain it

11. Rules Summary

File Rules

Rule Description
One file per part/assembly No duplicates
Filename is number only No description, no revision
Current file is latest revision Always
Archive is read-only Never edit archived files

Editing Rules

Rule Description
Check out before editing Always update checkout.json
Check in after editing Always clear checkout.json
Never edit checked-out files Wait for other user
Never edit released files Create new revision first

Revision Rules

Rule Description
New parts start at Rev A Always
Revision changes only on released modification Not on working edits
Archive before incrementing revision Always preserve old revision
Document reason for revision In ChangeNote and revision_history
